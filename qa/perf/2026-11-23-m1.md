# Perf report — milestone 1 (2026-11-23)

**Hardware caveat:** captured in a cloud container with **no GPU** — Forward+ ran on lavapipe
(software Vulkan), Compatibility on llvmpipe (software GL), the browser on SwiftShader/llvmpipe
WebGL. Frame times below show the pipeline works; they are **not** representative of the reference
hardware in spec §17.3. Real perf capture on a GTX 1060-class desktop and an iGPU laptop in Chrome
starts in milestone 2 with the perf-capture fly-through.
